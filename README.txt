今日の晩ごはん Webアプリ

1. Macで試す
   - index.html をブラウザで開くと基本機能は使えます。
   - PWAのインストール機能はHTTPS配信時に有効になります。

2. スマホに入れる
   - このフォルダを GitHub Pages / Netlify / Vercel などでHTTPS公開します。
   - iPhone: SafariでURLを開く → 共有 →「ホーム画面に追加」
   - Android: ChromeでURLを開く → メニュー →「アプリをインストール」または「ホーム画面に追加」

3. 内容
   - 冷蔵庫の食材入力
   - さっぱり / こってり
   - 米 / 麺
   - 辛さ
   - 候補料理、材料、手順
   - 別候補ボタン
   - PWA対応（manifest + service worker）
